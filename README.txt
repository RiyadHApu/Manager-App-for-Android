HOW TO GET THE APK (free, about 5 minutes, no computer software needed)
1. Create a free account at github.com and make a new PRIVATE repository.
2. Upload everything from this folder (including the hidden .github folder) to it.
   Easiest on a computer: unzip, then drag all files into the repository page.
3. Open the repository's "Actions" tab. "Build APK" runs automatically (about 3 minutes).
4. Open the finished run, download the "DeskbookManager-apk" file at the bottom, unzip it.
5. Copy DeskbookManager apk to your tablet, tap it, and allow "Install unknown apps" when asked.
